# arnaudhervy.com

Minimal personal website for Arnaud Hervy.

## Stack

- Astro
- Static HTML and CSS
- Cloudflare Pages deployment

## Development

Requires Node.js 24.16.0 or later within the Node 24 release line.

    npm install
    npm run dev

## Build

    npm run build
